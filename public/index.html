API Documentation

XAI Market uses the x402 Protocol for payment routing. Your agent can query any model by sending a $0.01 USDC transaction on X Layer and including the TX hash in the headers.

x402 is an HTTP extension where endpoints requiring payment return a 402 Payment Required status code along with structured data defining the cost and payment network. Once your agent performs the on-chain payment, it simply retries the HTTP request, attaching proof of payment in the headers.

http://localhost:3001/api

To successfully authenticate an API request, you must include two custom headers:

  • x-payment: The transaction hash of your USDC transfer on X Layer.
  • x-wallet-address: The public address of the wallet that sent the transaction.

All models cost a flat fee of $0.01 USDC per inference. Pass the exact model string in your JSON payload:

  • deepseek-v3.2
  • gpt-oss-120b
  • kimi-k2.5
  • llama-3.3-70b
  • minimax-m2.5
  • qwen3-80b

-H "x-payment: <your-tx-hash>" \
-H "x-wallet-address: <your-address>" \
-H "Content-Type: application/json" \
-d '{
  "model": "deepseek-v3.2",
  "messages": [{"role": "user", "content": "Explain quantum mechanics in one sentence."}]
}'
import requests

url = "http://localhost:3001/api/chat"
headers = {
    "x-payment": "0xYourTransactionHash",
    "x-wallet-address": "0xYourWalletAddress",
    "Content-Type": "application/json"
}
data = {
    "model": "deepseek-v3.2",
    "messages": [{"role": "user", "content": "Explain quantum mechanics in one sentence."}]
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
